# PhD: radial velocities and stellar activity

Code and notes from my PhD at the Cavendish Laboratory, University of Cambridge. The work looks at detecting Earth-like planets with precise radial velocities (RVs), and at stellar activity, the main obstacle to doing so. It connects to the [Terra Hunting Experiment](https://www.terrahunting.org/index.html).

## Projects

### [`Projects/simulating_rvs`](Projects/simulating_rvs)

Simulates the Sun's reflex RV due to the Solar System planets, then adds real solar activity from HARPS-N.

| Notebook | What it does |
| --- | --- |
| [`intro_to_rvs.ipynb`](Projects/simulating_rvs/intro_to_rvs.ipynb) | Computes Keplerian RV signals for each planet from the NASA Planetary Fact Sheet (semi-amplitudes, solving Kepler's equation for the anomalies), sums them, and compares the result with and without Jupiter and Saturn. Covers Doppler shifts. Saves the model to `solar_system_rvs.npz`. |
| [`rv_with_stellar_activity.ipynb`](Projects/simulating_rvs/rv_with_stellar_activity.ipynb) | Loads the HARPS-N solar RVs (2015–2025). Bins them per day, applies 30-day smoothing, and corrects for the magnetic cycle using the Bremen Mg II index. Then computes Lomb-Scargle periodograms and injects the activity into the planetary signal to see what survives.

Run `intro_to_rvs` first, since the second notebook loads its output.

#### Data

These files go in `Projects/simulating_rvs/data/`:

- `harpn_sun_release_timeseries_2015-2025.csv`: HARPS-N solar RVs, from [DACE](https://dace.unige.ch/openData/?record=10.82180/dace-h4s8lp7c$0) (Dumusque et al. 2025).
- `solar_system_rvs.npz`: generated by `intro_to_rvs.ipynb`.
